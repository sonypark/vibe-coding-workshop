| 파일 | 실습 | 시간 |
|---|---|---|
| day1/step1.html | ① 자기소개 카드 — 첫 배포용 최소 파일 | 0:12–0:30 |
| day1/step2.html | ③ D-day 위젯 추가 | 1:10–1:35 |

## opendata — 공공데이터

### 데이터 두 종류
| 파일 | 내용 | 크기 | 쓰임 |
|---|---|---|---|
| `subway.json` | 서울교통공사 지하철 혼잡도 · 1~8호선 245개 역 · 요일별 · 30분 단위 | 1,671건 · 1.0MB | **기본** |
| `bike.json` | 서울시 공공자전거 신규가입자 · 2026년 1~6월 | 96건 · 8KB | 대안 |

**지하철**은 역 이름이 있어 **검색**이 되고, 시간대가 있어 **그래프**가 됩니다. 실습 ①②에 모두 맞습니다.
**따릉이**는 96줄뿐이라 가볍고, 검색보다 **비교**(나이대·성별·월별)가 어울립니다. 빠른 학생용 두 번째 데이터로 쓰세요.

### 변환 다시 돌리기
원본 CSV는 **UTF-8**이라 엑셀로 그냥 열어도 됩니다. 변환을 다시 돌리려면 이 폴더에서:
```
python3 convert.py
```
`convert.py` 는 UTF-8을 기본으로 읽되, 포털에서 새로 받은 파일이 다른 인코딩이어도
알아서 처리합니다. 보통은 신경 쓸 일이 없습니다.

### 12분 시연 흐름
1. `subway.csv` 를 엑셀로 열어 보여줍니다 — **열이 44개**고 시간대가 옆으로 39칸 늘어서 있습니다.
   "이걸 그대로 웹페이지에 쓸 수 있을까요?"
2. `convert.py` 를 열어 **필요한 열만 고르는 부분**과 39칸을 하나로 묶는 부분을 짚습니다
3. 실행 → JSON 생성. **표의 한 줄이 `{ }` 하나가 됩니다** — 표와 JSON을 나란히 띄워 대응시켜 보여주세요
4. `subway.html` 을 열어 그 JSON이 화면이 된 모습을 보여줍니다

### 데이터에 숨어 있는 것 (좋은 교재)
- **혼잡도 100%는 정원**입니다. 그래서 **100%를 넘는 숫자가 나옵니다** — 최고 기록은 평일 2호선 사당 외선 08:30의 **147.7%**
- **평일과 일요일이 완전히 다릅니다.** 사당 외선은 평일 147.7%인데 일요일엔 61.2%이고, 봉우리 시각도 08:30 → 22:00으로 옮겨갑니다. *"왜?"* 를 묻기 좋은 지점
- **사당은 방향이 4개**입니다 — 2호선(내선·외선)과 4호선(상선·하선)이 만나는 환승역이라서
- 따릉이 나이대에 **`기타`** 가 있습니다. 나이를 안 적은 사람들 — 실제 데이터엔 늘 "어디에도 안 들어가는 칸"이 생깁니다
- 따릉이 가입자가 **1월 7,946명 → 5월 54,064명**. 계절이 데이터에 그대로 보입니다

### `최대혼잡`·`최대시각`은 원본에 없습니다
39개 시간대 중 가장 큰 값을 골라 `convert.py` 가 계산해 넣은 **파생 값**입니다.
카드 목록에 보여줄 대표 숫자가 필요해서 만든 것이고, 페이지 하단에도 그렇게 적어 뒀습니다.
"데이터에 있는 값"과 "내가 만든 값"을 구분해 주는 건 짚고 갈 만합니다.

### 최대 함정
**로컬에서 파일을 더블클릭해 열면 데이터가 안 나옵니다.** 코드가 틀린 게 아니라
브라우저가 막는 겁니다. 배포 주소나 VS Code Live Server로 열어야 합니다.

## teacher-demo — 서버로 API 키 숨기기 (심화 10분, 강사 화면공유만)

## 코드 작성 방침
- 변수 이름을 일부러 **한글**로 썼습니다 (`전체데이터`, `그리기`, `남은날`) — 초심자 인지 부담 감소.
  학생이 AI에게 받는 코드는 영어 변수명일 테니, 첫 시간에 **"이름은 아무렇게나 지어도 되는 것"**이라고
  한 번 짚어주세요
- 카드 목록 반응형: `repeat(auto-fill, minmax(220px, 1fr))` — 좁아지면 한 줄에 하나씩

## 학생이 자주 겪는 실수 (실제로 났던 것)
`<span>`은 **인라인 요소**라 `width`와 `height`가 적용되지 않습니다.
막대그래프를 span으로 만들면 채워지지 않고 회색 배경만 보입니다.
```css
.stat .f {
  display: block;   /* 이 한 줄이 없으면 막대가 안 채워집니다 */
  height: 100%;
}
```
`<div>`는 기본이 block이라 문제가 없습니다. "그래프가 안 나와요" 하면 여기부터 보세요.

`index.html`, `day1/*`, `lol/champions.html` 은 파일을 더블클릭해서 열어도 잘 동작합니다.
홈 → 각 폴더 → 예제까지 클릭으로 이동됩니다.

> **폴더 링크는 `day1/` 이 아니라 `day1/index.html` 로 적어야 합니다.**
> `day1/` 만 적으면 웹서버에서는 알아서 `index.html` 을 찾아주지만,
> `file://` 로 열면 서버가 없으므로 브라우저가 **폴더 목록 화면**(`Index of /…`)을 대신 보여줍니다.
> 깃허브에 올리면 둘 다 되지만, 수업에서는 학생들이 더블클릭으로 먼저 열어보므로
> **파일 이름까지 적는 쪽**으로 통일해 뒀습니다.

### 2) 반드시 서버로 열어야 하는 것
`opendata/*` 는 같은 폴더의 JSON을 읽기 때문에 **더블클릭하면 동작하지 않습니다.**
(`file://` 에서 다른 파일을 읽는 것을 브라우저가 막습니다.)
화면에 이렇게 안내가 뜨도록 해 뒀으니 당황하지 마세요.

```
데이터를 불러오지 못했습니다.
파일을 더블클릭해서 열면 브라우저가 막습니다.
VS Code의 Live Server로 열거나, 배포한 주소로 접속하세요.
```

둘 중 하나로 여세요.
- VS Code 확장 **Live Server** — 폴더 우클릭 → Open with Live Server
- 배포한 GitHub Pages 주소

> `lol/champions.html` 은 예외적으로 더블클릭해도 됩니다. 읽어오는 곳이 내 폴더가 아니라
> 라이엇 CDN이고, 그쪽 서버가 "누구한테서 오는 요청이든 받겠다"고 응답하기 때문입니다.
> **같은 `fetch` 인데 하나는 되고 하나는 막히는 이유** — 2회차에서 짚어주기 좋은 지점입니다.
