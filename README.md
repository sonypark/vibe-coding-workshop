## 폴더 구조

폴더 이름은 주소가 되므로 전부 영문입니다.

```

├─ README.md              ← 이 파일
├─ day1/                  1회차 — 자기소개 카드 만들기
│   ├─ index.html         목록 페이지
│   ├─ step1.html         자기소개 카드
│   ├─ step2.html         + D-day 카운터
│   ├─ step3.html         + 만다라트 3×3 (완성본)
│   ├─ step4.html         색만 바꾼 버전 (step3와 코드 동일)
│   └─ broken.html        (수업에서 뺌 · 파일만 남겨 둠)
├─ games/                 2회차 — 웹 게임 만들기
│   ├─ index.html         예시 6개 + 시작 프롬프트(복사 버튼) + 바꿔볼 것
│   ├─ mole.html          두더지 잡기        쉬움

│   ├─ updown.html        업다운             쉬움
│   ├─ memory.html        같은 그림 찾기     보통

│   └─ lol-quiz.html      롤 챔피언 맞히기   심화
├─ opendata/  lol/        수업에서 뺀 예전 자료 (아래 "보관 자료" 참고)
```

## 학생 작품 · 별 순위 (홈 화면)

홈 아래쪽 "학생 작품"에 학생 게임과 별 수가 순위대로 나옵니다.
**별을 가장 많이 받은 한 명에게 상품**을 주는 용도입니다.

### 학생 추가하기
`index.html` 맨 아래 `학생들` 목록에 한 줄씩 넣고 푸시합니다.
```js
const 학생들 = [
  { 이름: "김서연", github: "seoyeon-kim", 저장소: "game", 한줄: "두더지 대신 고양이 잡기" },
  { 이름: "박지훈", github: "jihoon-park", 저장소: "game", 한줄: "운석 피하기 2인용" },
];
```
- `저장소` 를 빼면 `아이디.github.io` (1회차 자기소개 카드)로 봅니다
- 2회차 게임은 학생들이 `game` 저장소에 올리므로 `저장소: "game"` 을 넣으세요
- 학생이 저장소 이름을 다르게 만들었으면 그 이름을 그대로 넣으면 됩니다
- 이름은 실명 대신 별명이나 성만 써도 됩니다. 홈은 공개 페이지입니다

카드마다 **🎮 작품 보기**(Pages 주소)와 **⭐ 별 주러 가기**(깃허브 저장소) 링크가 붙습니다.

### 별 세는 방식
- 깃허브 API(`api.github.com/repos/{아이디}/{저장소}`)의 `stargazers_count`를 **브라우저에서 직접** 읽습니다. 서버·키 없음
- 2026년 7월부터 "별 누른 사람 목록"(`/stargazers`)은 저장소 주인·협업자만 볼 수 있어서(로그인 없이 부르면 401), 사람 목록 대신 개수만 씁니다
- 그래서 **자기 저장소에 누른 별도 1개로 셉니다.** "내 저장소에는 누르지 않기"를 규칙으로 안내하세요
- 1~3위에 메달, 1등이 여럿이면 "공동 1위"로 표시
- 별 수는 **5분 동안 기억**합니다. 브라우저를 새로고침해도 깃허브에 다시 묻지 않습니다
- 화면의 **↻ 새로고침** 버튼은 기억한 값을 무시하고 바로 다시 셉니다. 누르면 10초 동안 잠깁니다
- 저장소가 없으면 "저장소를 못 찾음", 한도에 걸리면 "잠시 후 다시"가 뜹니다

> ⚠ **깃허브는 로그인 없는 요청을 인터넷 주소(IP) 하나당 1시간에 60번까지만** 받습니다.
> 학생 15명이면 한 번 셀 때 15번입니다. 학생들은 각자 집에서 보니 괜찮고,
> 강사 화면에서 "↻ 새로고침" 버튼을 서너 번 누르는 정도면 충분합니다.
> 동점 처리 방법(공동 수상·추첨 등)은 수업 전에 정해 공지하세요.

## 1회차 — 자기소개 카드 만들기

같은 `index.html`에 계속 덧붙입니다. 진도가 밀리거나 AI 사용 한도가 떨어진 학생에게
해당 단계 파일을 바로 건네주세요.

| 파일 | 쓰는 곳 | 시간 |
|---|---|---|
| day1/step2.html | 실습 ① 카드 + D-day 의 완성본 | 0:15–0:40 |
| day1/step3.html · step4.html | 실습 ② **코드는 똑같고** 색 6개 + 이모지 1개만 다름. 나란히 띄워 비교 | 0:40–0:55 |
| day1/step3.html | 실습 ③ 만다라트 완성본 | 1:05–1:45 |
| day1/step1.html | 실습 ④ 배포가 막힌 학생용 최소 파일 | 2:20–2:55 |

**실습 ②의 핵심**: AI 요청 0회. 학생이 "내가 코드를 만져서 화면을 바꿨다"를 처음 경험하는 지점입니다.
**실습 ④**: 저장소 이름 `아이디.github.io`, 반드시 Public. 주소는 `https://아이디.github.io`.

## 2회차 — 웹 게임 만들기

예시 게임을 하나 골라 AI로 만든 뒤, **모양·규칙·효과 세 가지**를 바꿔 내 게임으로 만듭니다.
처음 받은 그대로면 발표할 게 없습니다. **바꾼 게 곧 내 게임**입니다.

| 시간 | 내용 | AI |
|---|---|---|
| 0:00 | 오프닝 · 별 규칙 | 0 |
| 0:10 | 예시 게임 폰으로 해보기 (`games/index.html`) | 0 |
| 0:20 | 실습 ① 시작 프롬프트로 게임 하나 만들기 | 1회 |
| 0:45 | 실습 ② 코드 맨 위 숫자·이모지 직접 바꾸기 | 0 |
| 1:10 | 실습 ③ 모양·규칙·효과 하나씩 바꾸기 | 2~4회 |
| 1:50 | 실습 ④ `game` 저장소에 올리기 | 0 |
| 2:20 | 발표 — 한 사람 2분 | 0 |
| 2:50 | 별 주기 · 시상 | 0 |

쉬는 시간은 1:00, 2:10.

### 시작 프롬프트에 한 줄 덧붙이기
`games/index.html` 의 시작 프롬프트를 복사한 뒤, 학생들이 조건에 이 줄을 **직접 덧붙이게** 합니다.
```
- 바꾸기 쉬운 값(시간, 속도, 모양)은 코드 맨 위에 모으고 한글로 설명 달아줘
```
이 줄이 있어야 실습 ②를 AI 없이 할 수 있습니다. 예시 게임들도 같은 방식으로 맨 위에 값을 모아 뒀습니다.
```js
// dodge.html 맨 위
const 처음속도 = 3;          // 운석이 떨어지는 속도
const 빨라지는정도 = 0.0016;  // 시간이 갈수록 얼마나 빨라질지
const 운석모양 = "☄️";
const 우주선모양 = "🚀";
```

### 학생 게임 배포
1회차와 같은 네 단계인데 **저장소 이름만 `game`** 입니다.
New repository `game` (Public) → `index.html` 업로드 → Settings ▸ Pages ▸ `main` / `(root)` → 1~3분 뒤
`https://아이디.github.io/game/`

학생들이 채팅에 아이디와 게임 이름을 올리면, **두 번째 쉬는 시간(2:10) 안에** 홈의 `학생들` 목록에 넣고 푸시하세요.
그래야 발표와 별 주기 때 홈에서 바로 열립니다.

### 예시 게임별로 알아둘 것
- **두더지·반응속도·업다운**: 코드가 짧아 AI가 한 번에 잘 만듭니다. 처음이면 여기서 고르게 하세요
- **같은 그림 찾기**: `그림들` 배열의 이모지 8개만 바꾸면 테마가 바뀝니다
- **운석 피하기**: canvas로 화면을 계속 다시 그리는 구조라 AI가 한 번에 못 만들 때가 있습니다
- **롤 챔피언 맞히기**: 라이엇 공개 데이터(Data Dragon)를 불러옵니다. API 키는 필요 없고 더블클릭으로도 열립니다
  - 회사·학교·자녀 보호 필터에서 게임 도메인이 막힐 수 있습니다. 막히면 화면에 안내가 뜹니다
  - 페이지 하단에 `© Riot Games` 출처 표기가 있어야 합니다 (비상업 팬 콘텐츠 조건)
- 최고 기록은 `localStorage` 에 저장됩니다. 브라우저별로 따로 남습니다

### 학생이 자주 겪는 문제
| 증상 | 원인 · 해결 |
|---|---|
| 하얀 화면 | 코드를 일부만 복사함 → 처음부터 다시 복사. 또는 F12 ▸ Console 빨간 글씨를 AI에게 |
| 코드가 중간에 끊겨서 옴 | AI에게 "이어서 보여줘" |
| 숫자 바꿨더니 망가짐 | 이모지 값의 **따옴표를 지운 경우**가 대부분 |
| 고칠수록 더 이상해짐 | `backup.html` 로 돌아가서 새 대화로 다시 요청 |
| AI가 앞 내용을 잊음 | 새 대화 → 지금 코드 전체 붙여넣기 → 요청 한 줄 |
| `/game/` 주소에 자기소개 카드가 뜸 | 주소 끝 `/game/` 을 빼먹음 |
