[ 시작 전에 · 규칙 5개 ]
 1. 실습이 바뀌면 새 대화로.  카드의 (새 대화)/(이어서) 표시를 그대로 따르세요.
 2. "전체 코드 다시 줘" 금지.  "바뀐 부분만 보여줘"라고 하세요.
 3. 미리보기로 먼저 판단.  마음에 들 때만 복사해서 저장하세요.
 4. 긴 내용은 30줄만 붙여넣기.  데이터 전체를 붙이면 사용량이 한 번에 끝납니다.
 5. 색과 글자는 손으로.  AI에게 시킬 일이 아닙니다.

[ [대괄호] 표시 ]
 프롬프트 안의 [대괄호] 부분은 여러분이 바꿔 넣는 자리입니다.
 안 바꾸면 15명이 전부 똑같은 페이지를 만들게 됩니다.

[ 프롬프트 잘 쓰는 법 ]
 1) 눈에 보이는 것을 그대로 말한다
    X  예쁘게 만들어줘
    O  배경은 짙은 남색, 글씨는 흰색, 가운데 정렬, 모서리는 둥글게
 2) 한 번에 하나만 고친다
    X  색도 바꾸고 글씨도 키우고 버튼도 옮겨줘
    O  배경색만 먼저 바꿔줘  → 확인하고 → 다음 요청
 3) 안 되면 빨간 글씨를 통째로
    X  안 되는데요
    O  이 에러가 났어: Uncaught SyntaxError: Unexpected token '<'

  한 개 바꾸고 → 저장하고 → 새로고침. 이걸 반복하면 됩니다. 망가져도 괜찮습니다. Ctrl+Z로 되돌리면 됩니다.

------------------------------------------------------------------

--- 여기부터 복사 ---------------------------------------------
내 웹페이지를 휴대폰에서 열었더니 이렇게 나와.

⟨[증상을 그대로 적기 — 예: 옆으로 스크롤이 생겨 / 글자가 너무 작아 / 만다라트 9칸이 화면 밖으로 나가]⟩

휴대폰 세로 화면에서 안 깨지게 고쳐줘.

조건:
- PC에서 보이는 모양은 최대한 그대로 두고
- 전체 코드 말고, 고칠 부분만 보여주고 어디를 바꾸는지 알려줘
- 왜 그렇게 고치는지 한 줄로 설명해줘
--- 여기까지 복사 ---------------------------------------------

  AI에게 묻기 전에 이것부터
  코드 맨 위에 <meta name="viewport" ...> 줄이 있는지 확인 — 없으면 그것만 넣어도 대부분 해결됩니다
  width: 600px처럼 고정된 숫자를 찾아 max-width: 600px로 바꿔보세요. max-만 붙이면 되는 경우가 많습니다
  확인은 Chrome에서 F12 → Ctrl+Shift+M (Mac은 Cmd+Opt+M)

[5] 목록 + 검색 만들기  (새 대화)
    실습 ① · data.json을 올린 다음
------------------------------------------------------------------

--- 여기부터 복사 ---------------------------------------------
같은 폴더에 있는 data.json을 불러와서 보여주는 웹페이지를 만들어줘.
코딩은 처음이야.

만들 것:
- 데이터를 하나씩 카드로 만들어서 목록으로 표시
- 맨 위에 큰 제목과 한 줄 설명
- 그 아래 검색창. 글자를 치면 바로 걸러지게
- 지금 몇 개가 보이는지 숫자로 표시

카드에 보여줄 것:
- 제목으로 쓸 것: ⟨name⟩
- 작은 태그로 쓸 것: ⟨region⟩
- 회색 글씨로 쓸 것: ⟨address⟩
- 숫자로 쓸 것: ⟨seats(좌석), books(장서)⟩

검색은 ⟨name과 region⟩에서 찾아줘.

조건:
- 파일은 index.html 하나만. CSS와 자바스크립트도 안에
- fetch('./data.json')으로 불러와줘
- 못 불러왔을 때 화면에 "데이터를 불러오지 못했습니다"라고 나오게
- 맨 위에 <meta name="viewport" content="width=device-width, initial-scale=1"> 넣어줘
- 휴대폰 세로 화면에서 카드가 한 줄에 하나씩, 옆으로 스크롤 없이 보이게
- 각 부분이 무슨 일을 하는지 주석으로 짧게 달아줘
- 한 번에 보여줘

data.json은 이렇게 생겼어 (앞의 2개만):
⟨[여기에 data.json 파일을 열어서 앞부분 2개만 붙여넣기]⟩
--- 여기까지 복사 ---------------------------------------------

  주의
  data.json 전체를 붙여넣지 마세요. 앞의 2~3개면 충분합니다. 전체를 붙이면 그 한 번으로 오늘 사용량이 끝납니다
  노란 칸의 name, region 같은 것은 내가 고른 데이터의 열 이름입니다. data.json을 열어보면 나옵니다
  다 만들면 index.html과 data.json 두 개가 같은 저장소에 있어야 합니다
