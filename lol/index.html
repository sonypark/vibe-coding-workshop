데이터를 어디서 가져오나 — 두 곳을 순서대로 시도합니다. 먼저 라이엇 Data Dragon 에서 직접 (최신 버전 자동 감지), 실패하면 같은 폴더의 champion.json. 화면 위쪽에 어느 쪽에서 왔는지 표시됩니다.
게임 도메인이 막히는 네트워크가 있습니다 — 회사·학교망이나 자녀 보호 필터에서 ddragon.leagueoflegends.com 이 차단될 수 있습니다 (증상은 ERR_CONNECTION_CLOSED). 그럴 때를 대비해 강사용 champion.json 을 미리 받아두고, 막힌 학생에게 보내 이 폴더에 올리게 하세요.
수업에서 짚을 것 — 능력치가 전부 0인 챔피언이 있고(아크샨·렐·세라핀·벡스), 비에고의 마나는 10000이라 그래프를 혼자 다 차지합니다. 역할이 두 개인 챔피언도 많습니다. 실제 데이터에는 빠진 값과 이상치가 있다는 걸 눈으로 보는 순간입니다.
